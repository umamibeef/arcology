.. _appendix-script-api:

The script API
==============

.. rubric:: Generated by ``tools/gen_script_api.py`` from ``src/script``. Do not edit it by hand: change the source and run the generator.

Everything a script reaches is under one global, ``arc``. The pipeline hands a script an object: a handle of one kind, with a table of methods. ``o.kind`` names the kind, and ``o.alive`` says whether the record behind the handle is still the pipeline's current one. A handle is dead when the rule that was given it returns.

A rule is a function a script sets on ``arc.rules``. The pipeline calls the rule by name while it builds the mesh. Every index the API takes or answers counts from nought. A sequence a rule returns is Lua's own and counts from one.

arc.geo
~~~~~~~

A live table of the line works' numbers, and no functions. A read answers the value the build runs with, or nothing for a name no script has set. A write to a new name makes the number, so there is nothing to declare before a script invents one. ``pairs`` cannot walk it: ``arc.settings()`` answers a snapshot.

arc.rules
~~~~~~~~~

An empty table when the state comes up. A script sets a rule on it as a function, and the pipeline calls the rule by name while it builds the mesh. The rules the lint knows are listed under `The rules`_ below. A family's declaration may name a rule of its own invention for a stage, and the lint learns that name from ``arc.family.define``.

arc.tune
~~~~~~~~

A live table of the look's knobs, and no functions. A read answers the value the build runs with. A write moves the knob, holds it to its range, and asks for the world to be drawn again. A name that is not a knob is refused. ``pairs`` cannot walk it: ``arc.settings()`` answers a snapshot.

The handles
-----------

Each kind is one table of methods. ``KINDS[]`` in ``src/script/api_object.c`` lists them, and each table is written in the file that knows the thing, which is named under every kind below. A rule asks for the kind of its own name, and ``tools/script_api.py`` checks that every accessor in those files is named ``api_<kind>_<method>``.
